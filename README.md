# Microplastic Screening Detector

This project is an image-based screening tool for detecting possible particles
in microscope images.

## Features

- Upload JPG or PNG microscope images
- Detect possible particles using OpenCV
- Display threshold image
- Show particle count
- Display particle area chart
- Download CSV report
- Download processed result images

## Important Note

This is not a laboratory-confirmed microplastic test.
Detected objects are only possible particles.
